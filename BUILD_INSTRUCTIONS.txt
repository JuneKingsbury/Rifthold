===============================================================================
  RIFTHOLD - Build Instructions (Desktop & Android)
===============================================================================

This game uses Electron to package the browser game as a standalone desktop
executable, and Capacitor to package it as a native Android app.
electron-builder handles desktop installers; Capacitor generates a standard
Android Studio project.


--- PREREQUISITES ---

1. Node.js (v18 or later): https://nodejs.org
   Check: node --version

2. npm (comes with Node.js):
   Check: npm --version

3. For Windows builds from Mac, you need Wine:
   brew install --cask wine-stable

4. Install project dependencies (run once, or after pulling changes):
   npm install


--- RUNNING LOCALLY (DEV MODE) ---

  npm start

This launches the game in an Electron window. Use F12 to toggle DevTools.
All game features work identically to the browser version.


--- BUILDING EXECUTABLES ---

Build for a single platform:

  npm run dist:mac       Mac .dmg installer       -> dist/
  npm run dist:win       Windows .exe installer    -> dist/
  npm run dist:linux     Linux .AppImage and .deb  -> dist/

Build for all platforms at once:

  npm run dist:all

Output goes to the dist/ folder. Build artifacts:

  Platform   | File                          | Format
  -----------|-------------------------------|------------------
  Mac        | Rifthold-0.2.0.dmg            | Disk image
  Windows    | Rifthold Setup 0.2.0.exe      | NSIS installer
  Linux      | Rifthold-0.2.0.AppImage       | Portable binary
  Linux      | rifthold_0.2.0_amd64.deb      | Debian package


--- PLATFORM-SPECIFIC NOTES ---

Mac:
  - The .dmg is unsigned. Users may need to right-click > Open the first time,
    or go to System Preferences > Privacy & Security to allow it.
  - To distribute via the Mac App Store or avoid Gatekeeper warnings, you need
    an Apple Developer account and code signing. See:
    https://www.electron.build/code-signing

Windows:
  - Cross-compiling from Mac requires Wine (see prerequisites above).
  - The .exe installer is unsigned. Windows SmartScreen may show a warning on
    first run. To avoid this, purchase a code signing certificate. See:
    https://www.electron.build/code-signing
  - The NSIS installer lets users choose the install directory.

Linux:
  - AppImage is a portable single-file executable (chmod +x, then run).
  - .deb installs via: sudo dpkg -i rifthold_0.2.0_amd64.deb
  - Building .deb from Mac may require additional tools. AppImage works
    cross-platform without issues.


===============================================================================
  ANDROID BUILD
===============================================================================


--- ANDROID PREREQUISITES ---

1. Everything in the desktop prerequisites above (Node.js, npm, npm install).

2. Android Studio: https://developer.android.com/studio
   After installing, open Android Studio and let it download the Android SDK
   and build tools via the setup wizard.


--- BUILDING FOR ANDROID ---

Sync web assets and open Android Studio:

  npm run cap:android

This does three things:
  1. Copies game files into www/ (excluding Electron/dev files)
  2. Syncs web assets and Capacitor plugins into the Android project
  3. Opens the android/ project in Android Studio

If you only want to sync without opening Android Studio:

  npm run cap:sync


--- RUNNING ON DEVICE / EMULATOR ---

In Android Studio:

  1. Select a device or emulator from the device dropdown in the toolbar.
  2. Click the Run button (green play icon), or press Shift+F10.
  3. The game will install and launch on the selected device.

To build a debug APK without Android Studio:

  cd android && ./gradlew assembleDebug

Output: android/app/build/outputs/apk/debug/app-debug.apk


--- BUILDING FOR PLAY STORE ---

  1. In Android Studio: Build > Generate Signed Bundle / APK
  2. Choose "Android App Bundle" (.aab) for Play Store uploads
  3. Create or select a keystore for signing
  4. Build the release bundle

The .aab file will be in android/app/build/outputs/bundle/release/

To submit to Google Play, you need a Google Play Developer account ($25 one-time
fee): https://play.google.com/console


--- ANDROID-SPECIFIC NOTES ---

Orientation:
  The app is locked to landscape mode (sensorLandscape) in AndroidManifest.xml.

Screen:
  The status bar is hidden automatically. The screen stays awake while the game
  is running (FLAG_KEEP_SCREEN_ON).

Safe areas:
  UI elements (status bar, touch toolbar, footer) respect display cutouts and
  notches via CSS env(safe-area-inset-*).

Performance:
  On a fresh install (no existing settings), the game defaults to lower particle
  density (50%) and disables CRT effects for better mobile performance. Players
  can re-enable these in the settings menu.

Save data:
  Saves use localStorage inside the WebView, which persists across app restarts.
  The in-game Export button uses the Android share sheet to send save files.
  Import works via the standard file picker.

Touch input:
  The game already supports touch controls: tap to select, drag to pan,
  pinch to zoom, and a touch toolbar for common actions.


--- UPDATING THE ANDROID BUILD ---

After making changes to game code or assets:

  npm run cap:sync

This re-copies www/ and re-syncs plugins. Then rebuild in Android Studio.

If you change Capacitor plugins (add/remove/update in package.json):

  npm run cap:sync

Capacitor will update the Android project's plugin registrations automatically.

If you need to change Android-native settings (manifest, themes, icons):
  Edit files directly in android/app/src/main/. These changes survive cap sync.


--- ANDROID APP ICON ---

The default Capacitor icon is a placeholder. To set the Rifthold icon:

  Option A (manual):
    Generate icons at all required densities from build/icon.png and place them
    in android/app/src/main/res/mipmap-*/ic_launcher.png (and ic_launcher_round).
    Android requires these sizes: 48, 72, 96, 144, 192 (mdpi through xxxhdpi).

  Option B (automated):
    npm install -g @capacitor/assets
    Place a 1024x1024 source icon at assets/icon-only.png, then:
    npx capacitor-assets generate --android


===============================================================================
  SAVE DATA LOCATION
===============================================================================


--- SAVE DATA LOCATION ---

Player saves (localStorage) are stored in the platform's app data folder:

  Mac:     ~/Library/Application Support/Rifthold/
  Win:     %APPDATA%/Rifthold/
  Linux:   ~/.config/Rifthold/
  Android: WebView localStorage (internal app storage, not user-accessible)

Each platform's saves are separate. Players can use the in-game Export/Import
feature to transfer saves between browser, desktop, and mobile versions.


--- TROUBLESHOOTING ---

"npm start" shows a blank white window:
  Check the DevTools console (F12) for errors. Most likely a font or asset
  loading issue.

Audio doesn't play:
  Electron requires a user interaction before AudioContext can start (same as
  browsers). Click anywhere in the game window first.

"npm run dist:win" fails on Mac:
  Install Wine: brew install --cask wine-stable

Build output is very large:
  The asar packaging is enabled by default, which helps. If audio files make
  the build too large, consider compressing OGG files or excluding unused
  tracks. Unused tracks are already excluded in the build config.

Game runs but fonts look wrong:
  The fonts are bundled locally in the fonts/ directory. If fonts/fonts.css
  is missing or the woff2 files are missing, fonts will fall back to the
  browser default.
